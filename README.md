# FamilyTree Backend

A lightweight, API-driven backend for building and maintaining a dynamic, multi-generation family tree. This service enables users to authenticate, onboard family members, map relationships, and visualize lineage through a graph-based structure.

## 🚀 Objectives
- Provide a secure backend for managing user accounts and family profiles  
- Capture relationships (parent, child, sibling, spouse, extended family)  
- Expose the family graph via optimised endpoints  
- Support image uploads for profile photos  
- Enable invitations for family expansion  
- Serve a future React-based visual tree application

## 🛠 Tech Stack
- **Python 3.10+**  
- **FastAPI** for high-performance APIs  
- **Uvicorn** for local development server  
- **(Planned)** SQLAlchemy, PostgreSQL, JWT Auth, Graph libraries, S3/Blob storage
